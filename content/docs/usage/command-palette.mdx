---
title: Command palette
description: Run any command by name, with the ones you use most at the top.
---

Press **⌘K** (**Ctrl K** on Windows and Linux) to open the command palette, then type to find a command. Commands with a shortcut show it on the right, and **H** lists every shortcut.

## Frequent commands

The commands you run most appear first under **Frequent**, up to five of them. A command counts for more the more often and the more recently you ran it. A use from today counts in full, one from yesterday half, one from two days ago a third, and so on. Only your last 20 commands are remembered, on this device.

While you type, a frequent command is only moved up if it is already one of the closest matches, so it never jumps ahead of the command you're spelling out.

## Commands for what's on screen

Some pages add their own commands while they're open, listed under the page's name. They also appear in the shortcuts list (**H**) and go away when you leave the page.
