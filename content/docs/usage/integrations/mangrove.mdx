title: Mangrove
description: Open, community-written place reviews and ratings from Mangrove.
---

[Mangrove](https://mangrove.reviews) is an open review platform: every review is signed by its author and published under CC BY 4.0. The integration adds Mangrove reviews and ratings to place details.

Mangrove files place reviews under a location and a name rather than an OpenStreetMap ID, so Parchment matches a place by its name and coordinates (within about 50 m). Rating-only reviews count toward the average but are not listed.

Mangrove reviews are free and available to every user, not only those with premium data. When a premium source such as Foursquare also has a rating, that rating takes precedence as the headline score; Mangrove reviews still appear in the list.

---

## Capabilities

| Capability | Description |
|---|---|
| **Reviews** | Reviews and an average rating for a place, matched by name and location |

---

## Configuration

In **Settings → Integrations**, click the settings icon on the Mangrove card.

No configuration is required — Mangrove is a public API with no authentication. Add the integration and enable it.

Click **Test Connection** before saving.

---

## Writing reviews

Signed-in users can write a review from a place's **Reviews** tab: a star rating, optional text, and an optional display name. They can edit or delete it later from the same tab.

- Reviews are published openly on Mangrove under CC BY 4.0, and the form says so.
- Each user has one Mangrove reviewer key. It is created in the browser on their first review and stored in their end-to-end encrypted personal storage, so it follows them across devices and the server never sees it.
- Writing needs an encryption identity on the device and library write access (part of the default role). Users without these, or on a place that isn't from OpenStreetMap, see a **Write a review on Mangrove** link instead.
