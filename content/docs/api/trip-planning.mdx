      - content: >-
          Generate multiple trip options using different transportation modes
          and combinations. A request with more than two waypoints returns one
          whole journey per travel strategy, each carried from stop to stop — a
          journey that cycles to the first stop still has the bike at the
          second. Segments carry `legIndex` to say which hop they belong to. A
          transit leg's `routeOptions` lists the other lines running the same
          stops at that time. Its `shortName` names the line; a line with no
          GTFS short name reads by its long name, and the train number moves to
          `trip.shortName`. A walking segment with `streetTransfer` leaves the
          paid area between stations the agency does not connect, so the next
          ride is a new fare. Street segments carry `hazards`: crosswalks, rail
          crossings, tunnels, fords, steep grades, stairs, sharp curves and the
          like, placed by distance along the segment. Comfort hazards (rough
          surfaces, dismount sections, ferries) appear only for users with
          premium navigation. Driving segments carry `drivingSide`, and where
          the routing engine knows the lanes, `laneGeometry` (the route drawn in
          the lanes it takes, with `measures` giving the distance along
          `geometry` each coordinate stands for) and `lanePlan` (per instruction
          index, the approach lanes left to right and which lead on).
        heading: plan-a-multimodal-trip
