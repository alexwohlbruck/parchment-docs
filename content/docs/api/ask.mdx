          Ask runs on the user's own OpenRouter key when they have one,
          otherwise on the system key, which allows questions per UTC month by
          plan: `ask:trial` 5 (`ASK_QUESTIONS_TRIAL`), `ask:basic` 50
          (`ASK_QUESTIONS_BASIC`) and `premium:ask` 1000
          (`ASK_QUESTIONS_PREMIUM`), the best one held winning; 0 means no
          limit. On the system key, `quota` carries `used`, `limit`, `remaining`
          and `resetsAt`, or is null without a limit. `reason` is
          `not-configured` when no key exists at all, `not-permitted` when only
          the system key exists and the user holds none of those permissions,
          `quota-exceeded` (with `limit` and `resetsAt`) when this month's
          questions are used up, and `turned-off` when the user switched Ask off
          in their settings.
        heading: whether-the-user-can-use-ask
      - content: >-
          Streams Server-Sent Events while a language model searches Parchment's
          place data. `step` events report each search as it runs (`running`,
          then `done` or `failed`); `reach` carries a travel-time polygon when
          the question implies one; `answer` carries a short text and the cited
          places, every one of which came from a search; `error` and then `done`
          close the stream. `history` holds earlier turns of the same
          conversation, oldest first. `here` and `places` give the model names
          ("here", "home") it can route between; their coordinates go to tools,
          never into the prompt. A `trip` event carries the trip the answer
          recommends, for opening in Directions; `route` and `canvas` events
          name a route or canvas saved to the user's library. Every question
          counts toward the user's monthly usage; on the system key, a used-up
          allowance returns 429 with `reason: quota-exceeded` and `resetsAt`.
